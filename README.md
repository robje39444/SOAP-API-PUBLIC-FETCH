# SOAP-API-PUBLIC-FETCH
SOAP Client API Development with Validation and Service Hosting

From this assignment, i understand how Zeep turns the dictionaries into Python executables when you need to serialize to
JSON or write tests. The commands in the code went out (Get) to the public server XML and returned the data in a readable format. Zeep inspected the WSDL file for Football Pools and automatically generated a matching programmatic interface. This eliminates the need to manually build or parse complex XML documents. This showed me that a simple alignment of where you input the code on a specific level, drive which level of data the code will fetch.
